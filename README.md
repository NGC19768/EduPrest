# EduPrest
## Sistema de Control y Préstamo de Equipo Tecnologico

EduPrest es una aplicación web diseñada para gestionar el préstamo de equipos tecnológicos y recursos didácticos en instituciones educativas.
El sistema permite controlar la disponibilidad de los recursos, registrar prestamos y devoluciones. Al hacer esto se genera un historial de usuarios e incidencias, con el objetivo de reducir perdidas, cruce de horarios y prestamos vencidos.
